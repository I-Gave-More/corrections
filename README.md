# igavemore.com corrections

This repository only collects correction requests for [igavemore.com](https://igavemore.com).

To report a wrong, missing or outdated figure, [open a correction](../../issues/new?template=correction.yml).
Please include a public source. Accepted corrections are applied to the site's data, each with its source,
date and an archived copy. The rules for which gifts count are on the [methodology page](https://igavemore.com/methodology/).
